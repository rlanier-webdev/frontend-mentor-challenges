# Frontend Mentor Challenges

A collection of completed Frontend Mentor challenges showcasing responsive design, component-based layouts, and interactive JavaScript functionality.

## Projects

### 1. 3-Column Preview Card Component

A responsive three-column layout showcasing different car types (Sedans, SUVs, Luxury). Each column features an icon, heading, description text, and a "Learn More" button.

**Technologies:** HTML, CSS, JavaScript

**Features:**
- Three car category cards displayed side-by-side
- SVG icons for each category
- Responsive design with mobile-first approach
- Google Fonts (Big Shoulders Display, Lexend Deca)

[View Project](https://rlanier-webdev.github.io/frontend-mentor-challenges/3-column-preview-card-component)

---

### 2. Article Preview Component

An article preview card displaying an article title, description, author information with avatar, publication date, and an interactive share button that toggles social media sharing options.

**Technologies:** HTML, CSS, JavaScript

**Features:**
- Article preview card with image
- Author information section with avatar
- Interactive share button with toggle functionality
- Social media share options (Facebook, Twitter, Pinterest)
- Font Awesome icons

[View Project](https://rlanier-webdev.github.io/frontend-mentor-challenges/article-preview-component)

---

### 3. Intro Component with Signup Form

A landing page with a two-column layout featuring marketing copy and a signup form with validation. The form includes fields for first name, last name, email, and password with error handling.

**Technologies:** HTML, CSS, JavaScript

**Features:**
- Two-column responsive layout
- Form validation with error messages
- Error icons displayed on validation failure
- Call-to-action button
- Google Fonts (Poppins)

[View Project](https://rlanier-webdev.github.io/frontend-mentor-challenges/intro-component-with-signup-form)

---

### 4. Profile Card Component

A user profile card component displaying a user's information including profile image, name, age, location, and three statistics (Followers, Likes, Photos).

**Technologies:** HTML, CSS

**Features:**
- Profile card with user image and information
- Statistics section with Followers, Likes, and Photos
- Decorative top background element
- Clean, minimal card-based design
- Google Fonts (Kumbh Sans)

[View Project](https://rlanier-webdev.github.io/frontend-mentor-challenges/profile-card-component)

---

### 5. Single Price Grid Component

A pricing and community signup component with a grid layout. Features a community introduction section, monthly pricing display, and a benefits list with a sign up call-to-action.

**Technologies:** HTML, CSS

**Features:**
- CSS Grid layout with three sections
- Monthly pricing display ($29/month)
- Benefits and features list
- Accessible sign up button
- Google Fonts (Karla)

[View Project](https://rlanier-webdev.github.io/frontend-mentor-challenges/single-price-grid-component)
